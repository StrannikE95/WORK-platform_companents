Задача - описать правила развертывания и настройки (!) платформенного ПО таким образом, чтобы экземпляр удовлетворял требованиям
+ отказоустойчивости
+ производительности (машиабирование)
+ безопасности

Диалоги заводятся под отдельное ПО

+ Ответы оформляй отдельными *.md - файлами в папке \Out
+ Название файла с ответами = название ПО
+ Структура ответа: 
    + Голоссарий терминов
    + Основные элементы системы и зависимости
    + Краткие вводные (что считаешь нужным рассказать)
    + Допущения (условия которые ты сделал готовя ответ)    
    + Краткое описание ключевых этапов и элементов развертывания (не нужно копировать весь мануал)
        + Для 1 инстанса (тестовый стенд, 1 ЦОД, без нагрузки)
        + Для прода (3 ЦОДа, нагрузка)
