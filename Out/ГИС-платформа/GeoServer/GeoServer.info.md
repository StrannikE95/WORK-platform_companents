# GeoServer 2.24.4 — термины и сокращения

Словарь к файлу `GeoServer.md`. Список линейный, не таблица. Сверху — слова, без которых не читаются остальные. Аналогий нет: только что это делает в коде и на диске.

---

**Процесс** — запущенная программа: память и открытые файлы. GeoServer 2.24 — одно Java-приложение (WAR) в контейнере сервлетов (Tomcat 8.5/9 или Jetty из bin). Несколько реплик — несколько одинаковых JVM за HTTP-балансировщиком. В ядре нет голосования «большинство процессов живо — кластер работает»: жив один под и жив store — GetMap идёт.

**Файл / каталог на диске** — то, что остаётся после рестарта. Каталог данных (`GEOSERVER_DATA_DIR`): XML каталога слоёв, security, стили, логи. Тайлы GWC — в `GEOWEBCACHE_CACHE_DIR` или в S3. Потеря тома каталога = потеря публикации слоёв. Тайлы можно пересчитать; каталог — нет.

**TCP-порт** — номер в сети. HTTP приложения в официальном Docker — **8080** (`/geoserver`). Снаружи обычно **443** на Ingress. AJP **8009** наружу не открывать. **8443** — если включили HTTPS внутри контейнера. UDP нет. Между нодами GeoServer **нет** своего бинарного кластерного протокола в ядре.

**ЦОД** — отдельная площадка. Цель отказа в файле: пережить 1 ЦОД с нодами GeoServer, **если** PostGIS и каталог этот ЦОД тоже переживают.

**RTT** — время туда-обратно. Порога в мс нет. Мерить open/lock XML каталога и JDBC к PostGIS с ноды каждого ЦОДа, не ICMP ping. Общий NFS data dir через город — таймауты и битый XML.

**TLS** — шифрование байтов в сети. Обычно на Ingress перед 8080. Cookie сессии в проде: флаг **`Secure`**. ГОСТ/СКЗИ не заявлено. Штатный TLS JDK/Ingress — не КриптоПро.

**CVE** — опубликованная запись об ошибке безопасности. **CVE-2024-36401** — RCE, Critical; закрыт в **2.24.4** (18 июня 2024) вместе с SSRF в TestWfsPost. **CVE-2024-34696** — утечка env на Status; чинили в 2.24.4. Линия 2.24.x: **EOL август 2024**; всё, что нашли после июня 2024, проект **не чинит**.

**EOL** — дата, после которой авторы линейки не выпускают исправления. 2.24.x: stable сентябрь 2023, maintenance апрель 2024, EOL август 2024. На август 2026 линейка два года без патчей.

**Под (Pod)** — контейнер(ы) Kubernetes. Официального оператора под WAR 2.24 нет. Примитив: Deployment/StatefulSet + Ingress + PVC.

**PVC / RWO / RWX** — том Kubernetes. **RWO** — только одному поду. **RWX** — нескольким подам сразу. Data dir на RWO + 3 реплики = не стартуют или порча конфига.

**NFS** — сетевая файловая система. Один из официальных приёмов общего data dir — и классический источник file-lock и латентности.

**OGC** — консорциум, который стандартизирует HTTP-протоколы карт и объектов. GeoServer — сервер этих протоколов.

**WMS** — HTTP «нарисуй картинку карты» (PNG/JPEG) по слоям, bbox, стилю. Тяжёлый по CPU/RAM, особенно на растрах. GetMap — имя операции.

**WFS** — HTTP «отдай объекты» (точки, линии, полигоны) в GML/GeoJSON. Чтение. GetFeature — имя операции.

**WFS-T** — то же + **запись**: клиент может менять объекты в хранилище HTTP-транзакцией. В проде файла часто выключают. Для «только чтение»: Service Level **Basic** (без транзакций) + JDBC-учётка store **read-only**.

**WCS** — HTTP «отдай растр/покрытие» (сетка значений, не картинка для глаз).

**WMTS / TMS / WMS-C** — HTTP «отдай готовый квадратик карты (тайл)». Обычно отдаёт **GeoWebCache**, не живой WMS.

**WPS** — HTTP «посчитай на сервере» (буфер, пересечение). Состояние jobs между нодами **не** общее без отдельного расширения (wps-cluster-jdbc/hazelcast).

**Слой (layer)** — опубликованный набор: клиент просит слой по имени (`workspace:name`).

**Workspace** — пространство имён слоёв (чтобы `topp:states` не пересекался с `egrn:parcel`).

**DataStore / CoverageStore** — подключение к данным: PostGIS, Shapefile, GeoTIFF. Слой смотрит в store, а не лежит внутри процесса GeoServer. Упал store — карта пустая при живом UI.

**Каталог (catalog)** — список workspace / store / layer / стилей. В классическом GeoServer это XML-файлы в **data directory**. Официальная проблема кластера: *management of changes to the data directory*.

**Data directory (`GEOSERVER_DATA_DIR`)** — каталог на диске: конфиг, security, логи, иногда стили и файловые данные. В проде дока *highly recommended* вынести наружу. В Docker 2.24 пример: `/opt/geoserver_data`. Без внешнего каталога апгрейд и бэкап ломаются.

**GeoWebCache (GWC)** — встроенный тайловый кэш: сохраняет уже нарисованные тайлы на диск/S3, чтобы не гонять WMS каждый раз.

**`GEOWEBCACHE_CACHE_DIR`** — где лежат файлы тайлов. Если у каждой ноды свой каталог — кэш **разный**, клиент после балансировки видит то старый тайл, то промах.

**gwc-s3** — stable-расширение: тайлы в S3-совместимом object storage.

**Capabilities** — XML «что умеет сервис»: список слоёв, SRS, операции. URL в нём должен быть **публичным** (`PROXY_BASE_URL`), иначе клиенты ходят на внутренний `http://pod:8080`.

**`PROXY_BASE_URL`** — базовый URL «как нас видит мир» за reverse proxy (`https://maps.example.ru/geoserver`). Настроить до раздачи GetCapabilities.

**SLD / стиль** — правила отрисовки (цвет, подпись). Файлы стилей — часть конфига; в кластере их тоже надо синхронизировать.

**PostGIS** — расширение PostgreSQL для геометрии. Типичное **хранилище объектов**, которое GeoServer читает JDBC. Это **другое** ПО. HA PostGIS — отдельный проект. JMS-дока: **NO DATA IS SENT THROUGH THE JMS CHANNEL**.

**Растр / вектор** — растр — картинка/сетка (космос, ЦМР). Вектор — объекты с атрибутами. Официально: вектору «больше heap» почти не помогает (стриминг); растру — помогает tile cache в heap.

**JAI / JAI-EXT / Marlin** — библиотеки отрисовки в JVM. В 2.24 JAI-EXT **включён по умолчанию**. Marlin — растеризатор линий; на Java 17 в bin-сборке его иногда приходится снимать.

**Control-flow** — **стабильное** расширение: очередь и лимиты параллельных OWS-запросов в файле `controlflow.properties`, чтобы один клиент не убил JVM. Считает **ноду**, не кластер. Ориентир модуля: на локальных данных пик GetMap около **2 × число ядер** параллельных запросов на инстанс — стартовая формула, не смета. Пример в доке — на **4 ядра**.

**Community-модуль** — плагин **не** из официального релиза на SourceForge. Экспериментальный, «as is». JAR с **nightly** на релиз **2.24.4** часто **не встанет**. Нужна сборка с git-тега `2.24.4`.

**JMS-cluster** — community: шина ActiveMQ разносит **изменения каталога** Primary → Replica. **Данные слоёв по JMS не едут.** Multicast по умолчанию **плохо** живёт в Kubernetes; брокер должен быть внешний с failover. На Primary **нельзя** catalog reload (шторм на replica). На pure replica **нельзя** менять конфиг. Не ставить два механизма кластера сразу (JMS + JDBCConfig).

**JDBCConfig / JDBCStore** — community: каталог (и файлы стилей/иконок) в СУБД, ноды подтягивают изменения без полного рестарта. Цена — нагрузка на БД. Security xml дока/практика часто **локальные**. HA теперь у **той** БД.

**GeoServer Cloud** — **другой** продукт: микросервисы WMS/WFS/REST + брокер + `pgconfig`. Официально рекомендуют для Kubernetes. Это **не** «GeoServer 2.24 WAR в трёх репликах».

**Primary / Replica (JMS)** — кто имеет право менять конфиг / кто только принимает сообщения. Путать с PostgreSQL primary — ошибка.

**`CLUSTER_CONFIG_DIR`** — если **общий** data dir на несколько JVM — у каждой свой каталог `cluster.properties`. Иначе ноды перетирают настройки кластера.

**CSRF** — защита админки: браузер должен прислать Origin/токен этого же сайта. За proxy без whitelist ломает UI (`Origin does not correspond to request`). Не выключать `GEOSERVER_CSRF_DISABLED=true`; задать `GEOSERVER_CSRF_WHITELIST` доменами.

**XXE / entity resolution** — разбор XML во входных HTTP-запросах. Без allow-list сервер может сходить на внешние URL (и иногда к файлам) по указке клиента. По умолчанию http/https **не ограничены**, `file:` режется. Для прода: `-DENTITY_RESOLUTION_ALLOWLIST=...`. Галочка *Unrestricted XML External Entity Resolution* **снимает** ограничения.

**Master password** — отдельный пароль хранилища ключей/шифрования настроек security. В Docker README: сменить вместе с `admin`. Для образа 2.24.4 проверять инструкцию тега, не копировать 2.28 вслепую.

**`admin` / `geoserver`** — дефолтный логин админки. Известен всем, кто открывал документацию. Сменить до любого Ingress наружу.

**Sticky session** — балансировщик всегда шлёт одного пользователя на одну ноду. Нужно админке/некоторым WPS, не нужно обычному GetMap.

**RPO / RTO** — сколько конфига/тайлов готовы потерять / как быстро поднять карту снова.

**Java 11** — протестированный runtime линии 2.24. **Java 17** в доке 2.24 — *experimental only*. Tomcat **8.5 или 9**. Tomcat 10+ (Jakarta) — **не** тот WAR.

**WAR** — архив Java-приложения, который кладут в Tomcat. Расширения — zip **той же** minor/patch, в `WEB-INF/lib` одинаковым набором на все ноды.

**REST API** — HTTP для смены каталога автоматически. Менять каталог лучше через один узел или через механизм синка.

**Web Admin (`/geoserver/web`)** — UI людей. В проде часто **выключают** (`GEOSERVER_CONSOLE_DISABLED=true`), REST — из внутренней сети.

**Security subsystem** — пользователи, роли, «кто видит слой». Конфиг в data dir (`security/`). Keycloak из коробки нет (есть community OIDC/Keycloak).

**CORS** — HTTP-заголовки, с какого Origin браузер может звать API. В примерах Tomcat/Jetty — `allowedOrigins=*`. Для закрытого контура нужен явный origin UI.

**`X-Frame-Options=SAMEORIGIN`** — дефолт: не вставлять админку в чужой iframe.

**HSTS** — HTTP-заголовок «только HTTPS». По умолчанию **выключен** (`geoserver.hsts.shouldSetPolicy`).

**HttpOnly / Secure (cookie)** — HttpOnly есть; **Secure в проде включить**, если админка только по HTTPS.

**`GEOSERVER_MODULE_SYSTEM_ENVIRONMENT_STATUS_ENABLED`** — показ env/sysprops на Status/REST. В проде **false** (CVE-2024-34696).

**Лог PRODUCTION** — профиль логирования. Путь `GEOSERVER_LOG_LOCATION` зафиксировать снаружи.

**`topp:states`** — demo-слой. В проде снять вместе с sample data.

**control-flow ключи** — `timeout`, `ows.global`, `ows.wms.getmap`, `ows.gwc`, `user`/`ip`.

**G1 (`-XX:+UseG1GC`)** — сборщик мусора JVM. Для постоянной нагрузки и кучи **≥ 6 GB** рекомендуют G1. `-Xms` = `-Xmx`, задать явно (дефолт JVM часто **¼ RAM** хоста). `-XX:SoftRefLRUPolicyMSPerMB=36000` — дока просит для кэша SRS/store. Memory limit Kubernetes **выше** heap (native, GWC, JAI).

**serviceStrategy** — в примерах доки **PARTIAL-BUFFER2**. `SPEED` прячет ошибки, `BUFFER` жрёт RAM.

**GetCapabilities / GetMap / GetFeature** — операции OGC: список слоёв, картинка, объекты.

**HEALTHCHECK_URL** — в README образа проверка на логотип: процесс жив, не «PostGIS отвечает». Readiness прода: GetMap известного слоя 200.

**Image tag `2.24.x`** — в главе Docker User Manual это **nightly / SNAPSHOT**, *not suitable for production*. Прод/препрод: **2.24.4**, если тег есть в `docker.osgeo.org`; иначе свой образ из WAR 2.24.4.

**GPL** — лицензия GeoServer. Не Apache 2.0. Про условия распространения модификаций, не license-server.

**GeoData (IT Geo)** — другой продукт (Cassandra/Kafka). Не обёртка над GeoServer 2.24.

**SoT** — GeoServer публикует то, что лежит в store. Эталон контуров — озеро / PostgreSQL / кадастр, не Shapefile внутри data dir.

**OOM** — JVM убита лимитом памяти. Control-flow как раз против этого на GetMap.

Источники формулировок: глоссарий и тело `GeoServer.md`. Новых порогов RTT и размеров диска здесь нет.
