# Luxms BI 12.x — термины и сокращения

Словарь к файлу `Luxms BI.md`. Список линейный, не таблица. Сверху — слова, без которых не читаются остальные. Аналогий нет: только что это делает в коде и на диске.

---

**Процесс** — запущенная программа: память и открытые файлы. Luxms BI — несколько процессов: Nginx (`luxmsbi-web`), Java (`luxmsbi-appserver`), PostgreSQL, KeyDB, NATS, Consul, Patroni, datagate, bins. Упал Postgres primary без failover — живой nginx UI не отдаст данные.

**Файл / каталог на диске** — то, что остаётся после рестарта. `$PGDATA` ядра — метаданные, права, локальные витрины. NATS JetStream — `/opt/nats` (в гайде старт **10 ГиБ**). Data dir Postgres: не NFS; `noatime`. Реплика Patroni не заменяет backup: `DROP` уедет на копию.

**TCP-порт** — номер в сети. Снаружи люди — **443** (TLS на балансировщике). PostgreSQL **5432**, KeyDB **6379**. NATS 12.x: клиенты **4222**, cluster **6222**, monitor **8222**. Из гайда 9.2 (сверить с sysadm-guide вашей сборки 12.x): web HTTP **80**, appserver **8080**, datagate **8200**, importer **8192**, gateway **8889**, lua-webapi **8282**, Data Boring **1880**, RSocket **7200/7192**. **8888** в 12.x пример NATS — WebSocket; в 9.2 тот же номер — HTTP API BINS (конфликт на одном хосте проверять). Consul типично **8300/8301/8500/8600**.

**ЦОД** — отдельная площадка. Stretch = один логический контур (Postgres/NATS/Consul), железо в нескольких ЦОДах.

**RTT** — время туда-обратно. Порога в мс в публичных docs Luxms нет. Мерить **5432**, **6222**, Consul gossip, **6379**.

**TLS** — шифрование байтов в сети. Для нагрузки вендор рекомендует TLS **на балансировщике**, не на каждом luxmsbi-web. Пример NATS 12.x содержит `websocket { no_tls: true }`. Вендор **рекомендует не шифровать** Postgres во внутреннем сегменте «для нагрузки» — для контура с ПДн решение ИБ, не копировать plaintext. ГОСТ/СКЗИ «из коробки 12.x» нет.

**Под (Pod)** — если кладёте в Kubernetes: Postgres/NATS/KeyDB/Consul — StatefulSet + PVC, не Deployment с emptyDir. Публичного Helm-оператора 12.x в docs нет.

**PVC** — том на реплику. Не резать один PVC на три реплики Postgres.

**Luxms BI / ВУК** — платформа бизнес-аналитики: дэшборды, отчёты, self-service. Юридическое имя в реестре — «Визуальный управленческий контроль Luxms BI» (рег. № **3366**). Коммерческое ПО: без лицензии и персонального репозитория «скачать как Grafana OSS» нельзя. Точную сборку (12.0.2 vs 12.1.0) фиксируют договором.

**Датацентричная / двухзвенная архитектура** — основная бизнес-логика живёт **в PostgreSQL** (хранимые процедуры PL/pgSQL), а не в толстом Java-приложении. Между браузером и ответом БД — короткий путь: **Nginx**.

**Атлас** — набор аналитических приложений/дэшбордов в одном контуре (проект внутри BI).

**Датасет** — логическая единица: данные + настройки визуализации, которые фронт показывает пользователю.

**Куб** — массив «размерности × факты» модели вендора. Не OLAP-куб SSAS.

**Дэш / дэшборд** — один визуальный блок / экран из блоков.

**Front-end** — HTML5/JS в браузере. Сервер его **раздаёт**; логику ответа считает ядро в БД и микросервисы.

**luxmsbi-web** — веб-вход: отдельный Nginx + Lua (`luxmsbi-web.service`), **не** системный nginx ОС. HTTPS-вход, раздача UI, прокси на appserver/bins/БД.

**luxmsbi-appserver** — Java-сервис управления платформой и (в mono-сборке) работы с источниками. HTTP API, порт 8080 в гайде 9.2.

**appserver-mono** — «всё в одном» Java-пакете: управление + источники. Для теста удобно; для высокой нагрузки источники выносят в datagate.

**luxmsbi-datagate / Data Gateway Framework** — вынесенный доступ к внешним JDBC/источникам. Чтобы тяжёлый JDBC не шёл через тот же процесс, что UI. Порт 8200 в гайде 9.2. Исходящие: только озеро/витрины, не подсеть интеграционного API к ведомствам.

**luxmsbi-importer** — старый Java-импортёр по расписанию. В руководстве администратора **9.2**: для **новых** внедрений **не** рекомендуют. Порт 8192, если ещё жив.

**Data Boring** — встроенный ETL/ELT no/low-code (часть поставки). Это **не** интеграционное API к ведомствам. HTTP **1880** в гайде 9.2.

**BINS (luxmsbi-bins)** — сервис WebSocket: чтобы у другого пользователя дэшборд обновился без F5. Зависит от KeyDB и БД.

**KeyDB** — форк Redis: сессии, лимиты логина, pub/sub для realtime. Порт **6379**. При разносе хостов гайд 9.2 пишет `protected-mode no` и снять `bind 127.0.0.1` — в прод не тащить без firewall.

**NATS / JetStream** — внутренняя шина и хранилище объектов (конфиги, сгенерированные отчёты) между компонентами. Это **не** замена Apache Kafka. Кластер: уникальный `server_name` (FQDN), `routes` без «сам на себя». Пример 12.x: `no_auth_user: "be"` / `"fe"`, пароли `"x"`/`"y"` — демо-каркас. `max_payload: 16MB` в примере — потолок сообщения, не диск.

**FDW** — Foreign Data Wrapper PostgreSQL: таблица, которая на самом деле читает **другую** систему по сети. Живой запрос в источник без обязательного копирования. Бьёт по озеру-источнику.

**Слои данных (горячие / тёплые / холодные)** — идея вендора: то, что крутят на дэшборде, держат быстро (часто ClickHouse/Greenplum/витрина); архив — дешевле и медленнее.

**MPP СХД** — массово-параллельное хранилище под большие объёмы. В линейке Luxms целевые: **ClickHouse / Arenadata QuickMarts**, **Greenplum / Arenadata DB**. Ядро метаданных при этом всё равно PostgreSQL. «Поставили Luxms Cluster» ≠ HA ClickHouse.

**Patroni** — процесс рядом с PostgreSQL: пишет в DCS «кто лидер», при смерти лидера поднимает реплику. Сама Postgres кластером не становится. Клиенты ходят через VIP/HAProxy, не на зашитый IP старого лидера.

**DCS / Consul** — процессы, в которых Patroni хранит ключ «кто сейчас primary». Вендор в 12.x указывает **Consul 1.16.1**. Без живого DCS Patroni не знает, кого считать primary. Кворум Consul: для 3 серверов большинство = 2. Потеря 2 из 3 в мёртвом ЦОДе → запись BI встаёт.

**HAProxy (у Luxms)** — не только вход HTTPS. Ещё **пул соединений к Postgres** и разделение read/write (лидер vs реплики). В гайде 9.2 nginx `hash $upstream_cookie consistent` на appserver — **липкость к appserver желательна** (cookie `LuxmsBI-User-Session`).

**SSO / Keycloak** — единый вход. Вендор заявляет Keycloak, LDAP/AD, ЕСИА, JWT API-токены.

**RLS** — ограничение строк в SQL/ядре: пользователь видит не всю таблицу, а «свои» филиалы/объекты.

**Роли лицензии Viewer / Creator / Admin** — **лицензионный** потолок (не отменяется настройкой) плюс права внутри атласа. Viewer — смотреть; Creator — источники и ETL; Admin — всё, включая пользователей.

**Self-service** — сам подключил источник, сам собрал витрину и дэшборд. Только Creator/Admin.

**АРМ сотрудника безопасности** — отдельный UI для ИБ: сессии, аудит, инциденты. Не путать с Admin, который рисует дэшборды.

**ФСТЭК 4 УД, сертификат № 5055** — сертифицированная **сборка 11.0.x** (дата сертификата **15.04.2026**, поддержка этой версии до **15.04.2031**). **12.x в этой таблице нет.** Аттестация ГИС/КИИ — по сертифицированной сборке + контуру.

**Enterprise Cluster UL / L350** — лицензия «2 промышленных сервера в балансировке». Потолок **1000 одновременных сессий** в описании UL. Три площадки + MPP — отдельное согласование.

**DEVL** — лицензия на тест / непродуктовые среды.

**Appliance** — готовая VM (в руководстве 9.2 — ESXi с демо-датасетами) для учёбы, не прод.

**Stretch** — один логический кластер, железо в нескольких ЦОДах.

**RPO / RTO** — сколько данных готовы потерять / как быстро восстановиться.

**WMS / WFS** — в notes **12.0.2**: карты WMS/WFS. WMS — картинка карты по HTTP; WFS — объекты (точки/линии) по HTTP. Это слой карт в BI, не GeoServer как отдельный продукт этого файла.

**PL/pgSQL** — процедуры внутри PostgreSQL, где вендор держит бизнес-логику.

**Расширения Postgres** — обязательны из пакетов вендора: `pgsql-http`, `redis_pub_sub` / redis-pubsub, **plv8**, `redis_fdw` (в ФСТЭК-сборке — keydb-fdw). Не «с GitHub на глаз».

**luxmsbi-gateway** — шлюз в составе поставки (есть в ФСТЭК-таблице 11.x). Не путать с интеграционным API к ведомствам. Порт 8889 в 9.2.

**headless-chrome** — процесс отрисовки PNG/экспорта (в сертифицированном составе 11.x). Не в интернет.

**`bi` / `bi`** — учётка БД в примере Lua гайда 9.2. В прод не копировать.

**Антибрут** — `max_login_attempts = 0` в 9.2 значит **выкл**. Подбор пароля открыт, пока не включите.

**`rpmlimit = 0`** — лимит API выкл в 9.2.

**NTP** — синхронизация часов на всех узлах кластера.

**ОС из матрицы 12.x** — Astra Linux SE 1.7/1.8, РЕД ОС 7.3/8.0, Альт СП 10, Rocky Linux 9, MosOS Arbat 15.5. Не любой Ubuntu.

**Ядро СУБД** — PostgreSQL **15 или 17**, Postgres Pro 15/17, Tantor 15, Jatoba 5. Пакеты для PostgreSQL/Postgres Pro **13** вендор прекратил с **01.12.2025**.

**Состав рядом** — Nginx 1.xx, LuaJIT 2.1, Node.js 18/20, OpenJDK 17, KeyDB 6.x, ClickHouse 25.3 (если MPP), NATS 2.11.6, Consul 1.16.1, Patroni 3.2.x.

**ИИ-аналитик** — расширение с 12.0.0, отдельная лицензия. Куда уходят промпты в публичных notes не расписано. В первом проде файла — выкл.

**Ansible вендора** — штатный путь прода после согласования схемы. Самодельный Helm без их runbook = сами чините Patroni.

**Grafana / Prometheus** — операционный мониторинг Nginx/Postgres/NATS, не бизнес-дэшборды.

**Kafka** — источник для витрин, не транспорт ядра Luxms (ядро внутренне на NATS).

**SoT** — озеро / СУБД эталона. Копия в датасете Luxms ≠ эталон.

**Image / Docker Hub `luxmsbi:latest`** — публичного образа нет. Репозиторий персональный, с аутентификацией.

Источники формулировок: глоссарий и тело `Luxms BI.md`. Новых порогов RTT и размеров диска здесь нет.
