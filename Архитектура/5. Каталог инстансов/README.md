# Каталог инстансов — как пользоваться этой папкой

## Рабочий файл

Заполняем **`каталог.md`**. Состав строк — из `sample/`. Числа и «общий vs свой» — только ваши решения (и то, что уже зафиксировано в Task_6).

## Что лежит рядом и зачем

| Файл | Статус |
|---|---|
| `IT-landscape.md` | Прошлый артефакт общей картины (Task_5). **Не опора** для этого прохода: в постановке сказано, что там могут быть незамеченные допущения. Можно открыть как «память», нельзя переносить строку без повторного решения. |
| `IT-landscape-matrix.xlsx` | То же, табличный снимок прошлого. |

Когда каталог.md станет правдой, старые файлы лучше переименовать в `архив-task5-*` или убрать из этой папки — чтобы не было двух источников.
