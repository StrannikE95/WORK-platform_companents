## 5. Слой 1 — кратко (закрыт, не переоткрывать без противоречия)

Файл: `1. Модель сред/модель-сред.md`.

- Контуры этой итерации: **Dev** и **Prod**. Test будет до запуска Prod, площадка неизвестна; когда появится — тот же способ наката.
- Dev — отдельный K8s-кластер, не namespace в Prod. Состав продуктов полный, меньше ёмкость.
- Prod: **ЦОД-A** мозг, активный; **ЦОД-B** тёплый standby (стек запущен, нагрузку не принимает); **ЦОД-C** только копии, без K8s и HAProxy.
- Stretch stateful **нет**. VIP Keepalived не растягивать на A+B.
- DNS: одна зона `oreon.moskva.ru`; Dev-имена `dev.oreon.moskva.ru`; отдельной зоны prod нет.
- Непрерывность: внутри A — HA из паритета. Выключение контура на всём A → клиенты на B **без окна**. Смерть площадки A → **минуты**, дежурный; **можно потерять** хвост нереплицированных данных. Обновления только **rolling**.

## 7. Контекст диалога, которого нет в карточках Out

Чтобы не объяснять заново и не спутать слои:

**NetworkPolicy.** Файрвол под↔под (восток–запад). WAF/HAProxy это не закрывают. «Да» = CNI обязан уметь (не Flannel). Default-deny с дня 1 не выбран. Имя CNI можно позже, умение политик — нет.

**Ingress vs Gateway API vs API Gateway / BFF.**  
- Service выбирает **под**.  
- Ingress / Gateway API — HTTP-роутер **в кластере** (какой Host на какой Service), чтобы не плодить это в HAProxy. Пользователь выбрал **Gateway API** (новый API, не «вместо HAProxy»).  
- API Gateway / BFF — **прикладной** фасад (коллеги). Spring Cloud Gateway в `sample/`. Portal/BFF и APISIX в цепочке пользователя — этот слой.  
- SSE/WebSocket — ограничение на весь путь (timeouts, Upgrade), не третий вид шлюза.

**MOS OS.** Официально в организации MOS OS; на платформенный kubeadm 1.36 матрицы в репо нет. Выбрана Ubuntu. Luxms как раз перечисляет MosOS — остров. Не мешать ОС в одном пуле нод. CentOS Linux не рекомендовать (EOL); Stream ≠ Rocky.

**Docker Engine.** Не CRI. 24.0.9 EOL, не на ноды K8s. Compose не бой кроме исключения вендора. Ответ пользователя «иное» не расшифрован.

**IdP.** Keycloak = сервер идентификации **людей** (SSO). Не Vault, не ServiceAccount. Не Keycloak GeoData.

**ПРЕДЛОЖЕНО** в шаблонах — не меню из двух вариантов, а «подтвердите или замените». `edge-a`/`edge-b` — служебные имена VIP, не клиентские URL.
